Pullar プライバシーポリシー

発効日：2026年10月14日

Pullar は Ayubkhon Yuldashev によって開発されました。プライバシーに関する質問やリクエストについては、aubuldasev@gmail.com までご連絡ください。

サインインとプライバシーポリシーへの同意

Apple サインインは、プレミアム オファーの直前、および無料プランを含むアプリに入る前に必須です。導入セットアップと最初のトランザクションの下書きは、サインインする前に完了できます。セットアップが完了すると、ドラフトがアカウントに割り当てられます。ゲストモードはありません。サインインすると、必要に応じて Pullar アカウントが作成されるか、既存のアカウントが開きます。サインイン画面には、サインインすると、このプライバシー ポリシーに同意し、ここで説明されているデータ処理に同意することが示されます。各アカウントには個別のローカル台帳があり、認証によりプライベートな開発者チャットとクラウド音声が保護されます。サインアウトすると、次回のサインインのためにアカウント台帳が保存されます。サインインしたアカウントは、Supabase を通じてレコードをバックアップおよび復元します。

トランザクションと設定

収入と支出の記録、金額、日付、メモ、繰り返し設定、カテゴリ、通貨、表示精度、セットアップの完了、および保存された個人プランはローカルに保存され、サインインしたアカウントの Supabase にバックアップされます。 Pullar は、再インストール後など、再度サインインしたときにこのバックアップを取得し、デバイス間の変更を調整します。バックアップにはインターネット接続が必要です。サーバーに正常に到達しなかった変更は、アプリを削除した後は復元できません。アクセスはあなたのアカウントに制限されています。サービス管理者はデータベースにアクセスしてサービスを操作できます。ローカル ファイルは、Apple が管理するデバイスのバックアップに含まれる場合もあります。

Pullar の以前のバージョンで個人プランを作成した場合、その目標、ルーチンの長さ、チェックインの頻度はこのデバイスに保存されたままになります。そのプランのチェックイン リマインダーを有効にしている場合、Pullar はルーチン中に選択した頻度でローカル通知をスケジュールします。これらのリマインダーは、「設定」→「プラン」または「iOS 設定」でオフにできます。保存されたプランはアカウントのバックアップに含まれます。通知権限は各デバイスに固有のままです。

Apple でサインイン

Pullar は、Apple でサインインと Supabase を使用してアカウントを作成し、認証します。このサービスは、Apple が提供するアカウント ID、共有するために選択した電子メール アドレス (Apple プライベート リレー アドレスを含む)、および認証/セッション情報を処理します。 Pullar は Apple パスワードを受け取りません。 Supabase は、認証を操作し、サポート会話への安全なアクセスを行うためにこの情報を処理します。

開発者とのチャットとサポート

開発者にメッセージを送信すると、Supabase にはメッセージ テキスト、アカウント ID、タイムスタンプ、読み取りステータスが保存されます。開発者はこれらの会話を読んで返信できます。取引記録は自動的には含まれません。パスワード、支払いカード番号、または開発者に受け取られたくない情報は送信しないでください。サポートに電子メールを送信すると、開発者の電子メール サービスによって電子メール アドレスとメッセージが処理されて返信されます。

サービスプロバイダーと診断

Apple は、サインイン、アプリ配布、デバイスのバックアップ サービスを提供します。 Supabase は、認証とサポート チャット データベースを提供します。これらのプロバイダーは、ユーザーがサービスを使用するときに、IP アドレスなどのネットワーク情報や操作ログを処理する場合があります。 TestFlight は、Apple の TestFlight プライバシー規約に基づいて、Apple と開発者にテストのフィードバックとクラッシュまたは使用状況の診断を提供できます。

Pullar は EU の PostHog を使用し、初期設定、画面の閲覧、取引入力、音声入力、サブスクリプションの利用状況を分析します。イベントにはランダムなインストール識別子、ログイン後のアカウント識別子、アプリと端末のメタデータ、固定の利用情報が含まれます。PostHog は IP アドレスを受信し、それに基づいておおよその所在地を推定します。金額、タイトル、カテゴリ、日付、メモ、音声録音、文字起こし、メールアドレス、サポートメッセージは送信しません。セッション録画では、使いやすさの問題を分析するため、マスク済みの画面画像、タップ、スクロール、画面遷移を記録します。テキスト、入力欄、画像をマスクし、金融情報の画面、音声関連の内容、サポートの会話も送信前に端末上で隠します。マイクの音声、コンソールログ、ネットワークリクエストの内容は記録しません。過去の分析データの閲覧や削除は aubuldasev@gmail.com にご連絡ください。広告 SDK やアプリ間追跡は使用せず、個人情報を販売しません。

保存と削除

ローカル アカウントのトランザクションは、削除するか、このデバイスの Pullar を通じてそのアカウントを削除するか、アプリを削除するまで、デバイスに残ります。サーバーのバックアップはアカウントが削除されるまで残ります。アプリを削除するだけでは削除されません。以前のバージョンの未割り当てのローカル レコードは分離されたままとなり、サインインしたアカウントを削除しても自動的に消去されません。アカウント情報とサポート会話は、アカウントの削除をリクエストするまで、サービスを提供するために保持されます。 [設定] → [アカウントの削除] で削除を開始するか、アプリにアクセスできない場合は aubuldasev@gmail.com にお問い合わせください。アカウントを削除すると、アクティブなアカウント、クラウド トランザクション バックアップ、チャット記録が削除され、Pullar の Apple でサインインの認証が取り消されます。サービス プロバイダーのバックアップと操作ログは、保存期間にわたって残る場合があります。個別に保持されているデバイスのバックアップとサポート メールは、アプリ アカウントを削除しても自動的には消去されません。サポートメールの削除について開発者に連絡し、Apple の設定でデバイスのバックアップを管理してください。

中断されたアカウント削除から安全に回復するために、Pullar はリクエストを送信する前にデバイスにランダムな回復トークンを保存します。 Supabase は、そのハッシュとアカウント参照のみを保存します。アカウントを削除するとその参照がクリアされ、このデバイスは有効なサインイン セッションがなくても削除を確認できるようになります。レシートは、デバイスがローカル クリーンアップを確認するまで残ります。 Apple 認証コードやセッション トークンは含まれていません。未確認の削除試行はローカル記録に残ります。

あなたの選択

開発者に連絡して、個々のトランザクションを編集または削除したり、Apple プライベート リレー電子メールを選択したり、サポート メッセージの送信を回避したり、アカウントおよびサポート情報へのアクセス、修正、削除をリクエストしたりすることができます。正常にバックアップされなかったレコードは、開発者が復元することはできません。お住まいの地域によっては、追加のプライバシー権が適用される場合があります。

子供とポリシーの変更

Pullar は一般の読者を対象としており、13 歳未満の子供を対象としていません。子供が個人情報を提供したと思われる場合は、開発者に連絡してください。このポリシーは、アプリの変更に応じて更新される場合があります。現在のポリシーと発効日は、アプリとその公開プライバシー ページで確認できます。

プレミアム購入とトライアルのリマインダー

Apple はサブスクリプションの購入と支払い情報を処理します。 Pullar は、RevenueCat を使用して購入を検証し、プレミアム機能を有効にします。支払いカードの詳細は受信しません。 RevenueCat は、Pullar アカウント ID、サブスクリプション製品、購入および更新履歴、資格ステータス、購入とペイウォールの操作に必要な技術情報を受け取ります。プレミアム アクセスは、RevenueCat を通じて Pullar アカウントに関連付けられます。 Apple の請求は、購入に使用された App Store アカウントに関連付けられたままになります。 RevenueCat は、購入の復元とサブスクリプション管理もサポートしています。 RevenueCat は、サブスクリプションのパフォーマンスを測定するために、ペイウォールのビューと購入イベントも記録します。プライバシー ポリシーは、https://www.revenuecat.com/privacy. でご​​覧いただけます。 Pullar アカウントを削除しても、Apple サブスクリプションはキャンセルされません。 App Store アカウント設定でサブスクリプションを管理します。

クラウド音声入力の場合、Pullar の Supabase 関数は、アカウント ID を使用して、サインインしたアカウントの RevenueCat によるプレミアム資格を検証します。本番環境とサンドボックスの資格は個別にチェックされます。古いバージョンのアプリは、Apple の署名付きサブスクリプション トランザクションを Supabase 関数に送信し、Apple に現在のサブスクリプション ステータスを確認します。これにより、サブスクリプション製品、トランザクション識別子、有効期限/ステータス、および購入に添付された Pullar アカウント トークンが処理されます。サーバーは元のトランザクション識別子のハッシュとアカウント バインディングを保存し、1 つのサブスクリプションが複数のアカウントの音声リクエストに資金を提供するのを防ぎます。署名されたトランザクションは保存されません。アカウントを削除すると、アカウント参照はクリアされますが、複数のアカウントによる同時使用を防ぐためにハッシュは保持されます。アクティブな購入は、別のアクティブなアカウントにバインドされていない限り、Apple の署名付き証明を使用してアカウント削除後に復元できます。音声アクセスは Pullar アカウントに関連付けられており、プレミアム機能は RevenueCat を通じてチェックされます。アカウントへのアクセスについてサポートが必要な場合は、サポートにお問い合わせください。

試用版リマインダーを有効にして通知を許可すると、Pullar は、Apple が指定した試用版終了日を使用して、初回の請求前にローカル通知をスケジュールします。通知の配信はデバイスの設定によって異なります。プレミアム画面または iOS 設定でリマインダーを無効にすることができます。

音声入力

音声入力は任意で、マイクの許可、インターネット接続、アカウントへのサインインが必要です。サインイン前にプライバシーポリシーを確認できます。サインインすると、任意の音声入力のクラウド処理を含め、ポリシーに記載されたデータ処理に同意したことになります。音声はサーバーにアップロードされません。手動入力を使用する、音声入力を使用しない、またはiOS設定でマイクの許可を無効にすることができます。 Apple は、iOS 26 以降では SpeechAnalyzer を、iOS 18 ～ 25 では SFSpeechRecognizer を使用して、デバイス上の英語またはロシア語の録音を文字起こしします。古い API には音声認識権限も必要です。デバイス上の言語サポートが利用可能である必要があります。音声モデルはインターネットからのダウンロードが必要な場合があります。ローカル認識が利用できない場合は、手動入力を使用してください。アプリの言語がロシア語の場合、デフォルトの音声認識言語はロシア語です。それ以外のアプリ言語では英語になります。英語またはロシア語を選択できます。トランスクリプト、選択した通貨、現在の現地日付、および利用可能なカテゴリ名が Groq に送信され、ドラフトが準備されます。既存の取引履歴は送信されません。保存する前に、トランスクリプトを修正し、下書きを確認できます。

Pullar は、文字起こしが成功した後、または録音を閉じたり再開したりすると、一時オーディオ ファイルを削除します。そのサーバーは、オーディオ、トランスクリプト、または生成されたドラフトを保持しません。アカウントごとのリクエスト カウンターを保存して、使用制限を強制します。これらのカウンタはアカウントとともに削除されます。 Groq は、ゼロ データ保持が有効になっていない限り、信頼性または不正行為の監視のために入力と出力を最大 30 日間、または法的に必要な場合はそれ以上一時的に保持することがあります。 Pullar は、プロバイダーがデータを保持しないことを約束するものではありません。プロバイダーの処理場所と運用メタデータは、プロバイダーのサービス条件によって規定されます。したがって、音声による財務詳細は処理され、デバイスの外部に保持される可能性があります。プロバイダー情報は、https://console.groq.com/docs/your-data. で入手できます。保存されたトランザクションには、確認した詳細のみが含まれます。

エクスポートされたファイル

サインインしている各アカウントには、個別のローカル トランザクションとカテゴリがあります。認証は、クラウド音声とプライベート サポートへのアクセスも保護します。アカウント レコードはバックアップされ、サインインしているデバイス間で調整されます。バックアップまたは CSV をエクスポートすると、選択した宛先に財務データが書き込まれます。そのファイルにアクセスできる人は誰でもそれを読み取ることができます。バックアップをインポートすると、確認後にのみ現在のアカウントのレコードが置き換えられます。これらの変更もアカウントにバックアップされます。

ドラフトのセットアップ

最初のトランザクションとカテゴリの選択は、別のローカル設定領域に一時的に保存されます。セットアップがコミットされると、Pullar はそのコピーを削除します。中断された転送は、選択した宛先にバインドされ、レコードを複製せずに再試行されます。古いセットアップ コピーは、その所有権が確立された場合にのみ削除されます。未請求のセットアップ レコードは、バックアップとエクスポートでエクスポートまたは明示的にクリアできます。
